About

I'm a Cybersecurity Analyst & Full-Stack Software & Web app Engineer focused on threat detection, security operations, building secure systems and game development.

With 5+ years of experience, I specialize in building secure, scalable SaaS platforms. I created Speika.ai a web app that translates messages using AI technology allowing for real time language translation mantaing slang and expressions and memes, I also helped create Keymint.dev, a developer-first licensing system serving enterprise users; working on secure API design, authentication, digital signatures, JWT, TLS, and cryptographic license validation. My work emphasizes clean code, maintainability, and user experience. I also contributed to the development of Puzzle Scout & Africa's Legends a mobile game app when I was a Game Developer Intern at Leti Arts Ghana.

My cybersecurity interests center on SOC operations, threat detection, incident response, network security, cryptography, and PKI. I work with tools and technologies such as Splunk, Microsoft Sentinel, Wireshark, Linux, Python, and OpenSSL to investigate security events, analyze system activity, and strengthen defensive controls.

“In a world where systems are being built by autonomous language models the necessity of cyberspace security has never been more prevalent than ever.” - Me 😭
